# TC-071: Verify integer division, remainder and modulo scalar harnesses

## Description

This case verifies [FR-057](../functional/FR-057-integer-division-scalar-harnesses.md)
using:

- QSL-emitted packages admitted by Contract IR;
- public CG generation on both integer routes;
- host differentials against quire-exact;
- installed proof execution;
- scalar replay.

This case is planned. Generated proofs run only through the authorized runner
and budget: one Kani job at a time, under the caller's memory cap. The case
records measured verdicts and does not predict them. The `rem` steps need
FR-014-AC-81, verified in TC-024's remainder section. The native-route verdict
needs IR-1541.

## Test Procedure

1. **Selection and settlement (AC-1).**
   - Compile QSL sources over `x: Int[-10, 10]` and `y: Int[-3, 3]`: `x div y`
     and `x rem y` under each of the truncating, floor and Euclidean
     `integer_division` selections, and `x mod y`. Admit them through Contract
     IR.
   - Generate them through `generate_routed` and through
     `generate_routed_native`.
   - Assert each item settles `Supported`, or with one named FR-057 refusal.
     No item may settle `OperationNotRendered` or `Underived`.
   - Assert each `div` and `rem` harness's profile equals the claim's
     descriptor profile.
   - Inspect the catalog's scalar Kani projection.
2. **Draws and outcome mapping (AC-2).**
   - Inspect each generated harness. It must have one `i64` draw per operand
     over its lowered range and no assumption on the divisor, the dividend or
     the outcome.
   - It must map outcomes as FR-057 lists them, with the right refusal member
     for each operation.
   - On the host, evaluate the rendered assertion over the real oracle at
     `y = 0`, at an in-range member and at an out-of-range member.
   - Repeat with each mutated mapping: any `Refused` accepted, the other member
     accepted, `Incomplete` accepted, `Completed` accepted at zero. Each mutated
     mapping must fail.
3. **Expected-side inspection (AC-3).**
   - Each `div` expected side must use the relational window check and the
     division-free admission from `r(L)` and `r(U)`. Every product must keep
     the order quotient, then divisor.
   - Each `rem` and `mod` expected side must shift `rem_euclid` into the
     window.
   - No expected side may contain a forbidden token or a kernel or oracle path.
     `rem_euclid` is allowed in `rem` and `mod` only.
4. **Host differential (AC-4).**
   - Compile the rendered expected-side text as host Rust.
   - Compare it with quire-exact `divide` (both members) and `modulo` over
     `Integer`, per profile, over the FR-057-AC-4 grid and result ranges.
   - Assert that outcome kind, value and member agree, including at the named
     `div`, `rem` and `mod` vectors.
   - Swap two window rows and assert the differential fails.
5. **Zero divisor and `MIN / -1` (AC-5).**
   - At `y = 0`, assert `Undefined(DivisionByZero)` from the oracle, from
     quire-exact and from the harness assertion. Check every profile of `div`
     and `rem`, and `mod`.
   - Build `x div y` with an explicit `Int[i64::MIN, i64::MAX]` result range.
     Assert that `i64::MIN div -1` is
     `Refused(DivisionOutOfDomain { member: Quotient })` from both the oracle
     and quire-exact.
   - Build `x div y` with the inferred range over `x: Int[i64::MIN, 0]`. Assert
     `BoundNotI64` with the two canonical endpoints and no harness.
   - Assert that `i64::MIN rem -1` and `i64::MIN mod -1` complete `0`.
6. **Native route without the kernel plan (AC-6).** While quire-exact has no
   native division plan (IR-1541), assert for each of `div`, `rem` and `mod`:
   the typed native-plan refusal naming node and operation, no harness, no
   `NativeIntegerCapacity`, and an add sibling generated byte-identically.
7. **Healthy runs and measured widths (AC-7, AC-9).**
   - For each operation, shape and width FR-057 lists, run the healthy harness
     through the approved bounded path with the full ordered options, and
     record the measurement fields.
   - For each shape that finished, assert `Verified` with all checks and the
     one final cover satisfied (AC-7).
   - Record each shape that did not finish as a `not_tractable` row of the
     shipped scalar table.
   - Assert that the decider refuses at and above each row's width with no
     Kani launch, runs below it, and refuses no measured-verified shape.
   - If the rows split between a constant and a symbolic divisor, check the
     `divisor_constant` extension. Otherwise assert that no extension was added
     (AC-9).
8. **Mutants and replay (AC-8).**
   - Run each FR-057-AC-8 mutant over a fixture with a negative dividend, both
     divisor signs and zero, and an explicit result range that excludes some
     members.
   - The mutants are:
     - the oracle profile swaps for `div` and for `rem`;
     - the wrong-profile expected window;
     - `rem` rendered as `modulo`;
     - `rem` rendered with the quotient member;
     - `mod` rendered as the truncating and as the floor remainder;
     - the oracle completing at zero;
     - the expected side without its zero arm.
   - Assert each mutant is `Falsified` with in-domain playback.
   - Replay the decoded operands through the routed scalar replay and through
     quire-exact over `Integer`. Assert the kernel outcome differs from the
     mutant's.
9. **Non-`Verified` controls (AC-10).** Run separate controls against a
   division harness for an unsatisfied cover, a failed unwind, a timeout,
   memory exhaustion and a missing verdict. None may be `Verified`.
10. **Unchanged siblings (AC-11).**
    - Generate add, subtract, multiply, negate, the integer comparisons,
      implication, enum comparison and float comparison claims before and
      after the change. Assert the output is byte-identical.
    - Re-run FR-015-AC-115's reference-copy check.
11. **Run record (AC-12).** Inspect the run record for:
    - node and source association, operation, profile, route and ranges;
    - full argv with unwind options, target and limits;
    - checks, cover, playback, exit and terminal outcome.

    Tool versions are not required (QSL-406, EA-49).

## Expected Results

- Every shape measured tractable verifies against an expected side that shares
  no algorithm with the kernel.
- Each mutant fails with a disagreement that is in-domain and replayable.
- A zero divisor gives `Undefined(DivisionByZero)`. `MIN / -1` gives either a
  typed refusal or a `BoundNotI64` lowering refusal, consistent with the oracle
  and the runtime.
- Shapes that are unmeasured, did not finish, were refused or were not run
  receive no proof credit.

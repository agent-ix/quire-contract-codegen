# IR-948 V2 precondition, postcondition and invariant profiles under installed Kani

This file is the durable record behind the executed part of FR-015-AC-126 and FR-015-AC-129. The tests are in
`tests/it/kani_obligations_v2_profiles.rs`.

## Fixture

The `test/bank` domain package declares `Account.balance: Int[0, 100]` and `withdraw(amount: Int[0, 100])` whose frame
modifies `balance`. The QSL unit authors `pre CanAfford { amount <= self.balance }` and
`invariant NonNegative at current { self.balance >= 0 }` and the postcondition
`post Debited { self.balance <= pre(self.balance) - amount and self.balance >= pre(self.balance) - amount }` (QSL refuses the
specified `self.balance = pre(self.balance) - amount` with `undefined_expression (unproved-range)`, QSL-1901). Each harness is generated by
`negotiate_kani_native_obligations` from the package QSL emits, at unwind 8, and run through `execute_kani_obligation`
(the FR-017-AC-63 two-phase run) with a test-side `cgroup-memory.peak` source. The invariant counterexample is decoded and
replayed with `StateClauseReplay::new_invariant` and QSL's `replay_state_clause`.

## Postcondition harness

The postcondition harness (`tests/it/kani_obligations_v2_profiles.rs`, the default-lane test
`the_state_reading_postcondition_yields_a_harness_with_requires_and_a_mut_subject`) draws the `balance` pre-state and `amount`,
assumes `CanAfford` as the native expression `amount <= pre_balance`, copies the pre-state into `post_balance_current`, calls
`crate::subject::check(&mut post_balance_current, parameter_amount_current)`, asserts the produced balance in `[0, 100]`, computes
the independent native expectation over the pre-state copy and the produced state, runs the clause oracle and its two
arithmetic subterm probes, and asserts the oracle agrees with the expectation and that the clause holds. The mutant's
verdict comes from the witness phase; the proof phase of that run is the 19.7 GB peak, and the healthy proof peaks at 4.1 GB.

## Not established

- Postcondition spelled `self.balance = pre(self.balance) - amount`: QSL refuses it (QSL-1901, another lane). The conjunction
  of `<=` and `>=` is the accepted form and is what ran.
- The postcondition mutant's counterexample is decoded natively (`decode_v2_clause_falsification`) and the postcondition is
  evaluated natively over it; it is not replayed through QSL's `replay_state_clause`, which has no scalar V2
  postcondition envelope.
- Frame: the profile package grants its only field, so the frame generator has nothing forbidden to check; the frame
  members are those of FR-015-AC-31 and FR-015-AC-80 over the two-field twin.
- The four-kind run over one package therefore has not been executed as one run: the pre, post and invariant members have.

## Summary

Ticket: IR-1022 (design decision D1 on IR-1436). Spec-only PR #771 (head 36dc18d1, one commit on origin/main 67739cf5) specifying the two-phase Kani run: a proof phase under a proof option vector with no concrete playback, then, only after a failed non-unwinding check, a witness phase under the witness vector. Edits FR-015 (Outputs, AC-9, AC-41, AC-119), FR-017 (Description, Inputs, Behavior, AC-5, AC-21, AC-60, new AC-63), FR-028 (Behavior, AC-23), FR-029 (witness-disagreed row), FR-032 (replay input), TC-025, TC-027, TC-039 and tests.md. Reviewed against CG origin/main 67739cf5 src/kani/abi.rs:108-134 (adapter_options), src/kani/generate/spec.rs:1286-1311 (HarnessSpec::new_constrained), src/kani/identity.rs:393/624/810 (has_valid_provenance), src/kani/run/harness.rs:91-99, src/kani/run/execute.rs:400-440/834-890, src/kani/classify.rs:26-53/166-260, src/kani/output/report.rs:231-240/624-637, src/kani/output/playback.rs, src/kani/run/scalar.rs:347-373, src/kani/terminal.rs; Contract IR 43ef764 src/kani/outcome.rs (KaniOutcomeKind); quire-exact origin/main TC-931 Status and Linear IR-844 (19,671,392,256 B traced 40 GiB probe vs 8,183,332,864 B healthy sliced); quire matrix on the PR head.

## Verdict

CHANGES REQUIRED. The resource-stop rules are sound: the witness gets the identity's own ceilings, no ceiling is raised and the phase is not retried. The memory-fit caveat is honest that the controls stay unmet: 'a witness phase that stops on a resource limit is Inconclusive ... the control is unmet, not weakened', and 'no ceiling raise, smaller range or weaker assertion may stand in'. It does not weaken the mutant controls. Defects: some witness outcomes are unspecified, it is unclear whether the ceiling applies per phase or per run, and the fit numbers are not like-for-like.

| FND-001 | medium | The witness-outcome rules cover four cases: matching failure with playback, matching failure without playback, verified or non-matching failure, and wall-clock or memory stop. Several outcomes the existing classifier can produce are left out: no report (NoVerdict), CoverUnsatisfied or VacuousProof, an unwinding failure, a refused or malformed report, cancellation during the witness phase, and a launch refusal between phases. A proof-phase Failure entry with no failed check (e.g. AC-22's 'Failure entry with no checks and no timeout') is in neither the launch list nor the no-launch list. Fix: give each a typed result (for example cancellation -> Cancelled, other non-reproductions -> WitnessDisagreed or the witness's own refusal) and state the proof-phase no-check Failure case. | spec/kani/functional/FR-017-kani-execution-evidence.md:235 |
| FND-002 | medium | FR-028 holds 'the backend process tree' to the identity's wall-clock and memory ceilings and stops 'a run' that exceeds either. FR-017 now defines 'the run' as the two-phase run and launches the witness 'under the identity's same ProofCeilings'. So a two-phase run can take up to 2T end to end. FR-028 (Behavior and AC-2) does not say whether T bounds each launch or the whole run, and FR-034 deadline accounting inherits the same ambiguity. Fix: state in FR-028 that each phase launch is held to T and M separately, so the two-phase run can take up to 2T (or the opposite, if intended). | spec/kani/functional/FR-028-bounded-proof-ceilings.md:88 |
| FND-003 | low | The caveat 'quire-exact TC-931 measured 19.7 GB against 8.18 GB sliced on the meter harness (AD-007, IR-844)' compares two different runs. 19,671,392,256 B is the traced refusal-order mutant on the Peter-authorized 40 GiB probe. 8,183,332,864 B is the healthy sliced proof. The traced mutant at 16 GiB ran out of memory with no verdict (TC-931 Status). AD-007 does not contain these figures. The conclusion holds, but the comparison is not like-for-like. Fix: say 'the traced mutant peaked at 19.7 GB (and exhausted 16 GiB) where the healthy sliced proof peaked at 8.18 GB', and cite TC-931 Status/IR-844 rather than AD-007 for the numbers. | spec/kani/matrix/TC-025-bounded-kani-obligations.md:496 |

## Summary

Ticket: IR-639 (follow-up code ticket IR-1510). Spec-only PR #782 (head e28c9528, one commit) records the owner's minimal Kani run ownership decision: new ADR-007 (Accepted) supersedes ADR-005; FR-034 and TC-049 are deleted; FR-017-AC-65/66/67 and FR-028-AC-25 are new; FR-017-AC-19 is rewritten to the launch-unique named report file; FR-017-AC-54/55/56 are retired; FR-028-AC-21 is made environmental; TC-039 steps 23-26 and TC-043 steps 15-17 are added. Checked against CG source at origin/main 72c3403a (src/kani/run/{launch,namespace,owners,memory,report_file,execute}.rs, src/kani/classify.rs, src/kani/terminal.rs, src/kani/output/report.rs), Cargo.lock, Linear and GitHub. `git merge-tree` against origin/main 72c3403a (after #781) is clean (tree 0c03b4a8); the merged FR-017 holds AC-64 (#781) and AC-65..67 (#782) once each; GitHub reports MERGEABLE/BEHIND. `make spec` passes (rc 0, no new warning from this diff); `quire matrix` runs. No cargo and no Kani were run.

## Verdict

CHANGES REQUIRED. Retirement is structurally complete: no live spec/plan/docs/Makefile reference to FR-034, TC-049 or FR-017-AC-54..56 survives outside ADR-005's history and spec.md's retirement note; ADR-005 <-> ADR-007 supersedes edges and FR-017/FR-028 references to ADR-007 resolve; `make spec` passes; the merge with #781 is clean with no id collision. The defect is the memory vocabulary: the PR states once, in an interpretive note, that the runner-measured memory stop is PLANNED for removal, but leaves the normative statements and controls that require it.

## Summary

Ticket: IR-1441. Spec-only PR #767 (head 2362dae1) adding FR-052 and TC-066, the planned Kani row for the six text comparisons with a payload-byte bound P and carrier capacity C, with edits to FR-025 (Text ABI row, AC-7, new AC-16), FR-028, TC-036 step 16, TC-030 Text row, spec/kani/matrix/tests.md and spec/spec.md. Reviewed against origin/main cf10ec78 (includes FR-049/050/051) and quire-exact 5db2d5e3 (CG Cargo.lock pin; src/text.rs and accounting.rs unchanged at origin/main 4fe7df6), CG src/oracle/scalar/{derive,lower,render}.rs, src/core/ir/scalar_bounds.rs, src/routed/capability.rs, QSpec FR-196, Linear IR-1445, IR-261 and the IR-1436 design-review comment.

## Verdict

CHANGES REQUIRED. Verified against quire-exact 5db2d5e3 (CG Cargo.lock pin; src/text.rs and accounting.rs unchanged at origin/main 4fe7df6), CG src/oracle/scalar/{derive,lower,render}.rs, src/core/ir/scalar_bounds.rs, src/routed/capability.rs, QSpec FR-196, Linear IR-1445, IR-261 and the IR-1436 design-review comment. Correct: the six comparisons (text.eq/ne/lt/le/gt/ge) are FR-014 derivable and text.size is OperationNotDerivable (FR-014 line 301); the generated oracle is compare_text(left: &rt::Text, right: &rt::Text) -> Result<Outcome<bool>, OracleStop> with OracleStop::IllTyped (render.rs comparison_body), returns Outcome<bool> and reads no result bound (derive.rs Family::TextComparison carries only the operator), so the operand-only bound reading is consistent; compare_text returns Err(IllTyped{DistinctTextProfiles}) before any charge; Meter::charge returns only Incomplete, so Completed/Incomplete are the only Outcome variants (no Undefined, no Refused, since compare passes bound=None to prepare); the charge order (text.input-bytes with byte sum and two value occurrences, text.decode-scalars, then for normalizing profiles text.normalize-input and one running-count text.normalize-output per emitted scalar left then right, then text.result-retain) matches prepare/compare; TextProfile::order is bytes for binary-utf8 and chars().cmp otherwise, and UTF-8 byte order equals scalar order, so the byte-lexicographic native expression is right; P = max (binary-utf8) and 4 x max (unicode-scalars) are exact since TextType::admits measures the retained sequence, which equals the payload for those profiles; the ceiling paragraph matches TC-050 and the IR-1436 comment (2.6 GiB after count rewrite vs 1 GiB) and AC-8 never yields Verified above the request's ceiling. One high defect (an unreachable typed control) and two low ones.

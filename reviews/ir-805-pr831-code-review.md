## Verdict

**PASS with findings (no high).**

- **Oracle independence holds.** `D` is built from the test's authored constants (`POPULATION`,
  `LOWER`, `UPPER`, `unique`). Those same constants feed the QSL fixture's `bound ... [4]`, and
  `the_expected_domain_matches_the_package_projections` checks them against `select_population` and
  `relationship_end`. `D` reads nothing from a generated harness or from the mutated `LoweredGraph`.
  `mutant_is_detected` asserts `witness.original == end.declared()`.
- **`G` comes from the emitted source.** It is parsed from the generated proof's `kani::any()` draws
  and its `kani::assume(...)` lines. That includes each `Statement::Input` range assume
  (`render.rs:202-213`), the count/operand guards, the lower-degree guard, the in-population target
  guard and the uniqueness guards. I found no tautology.
- **No vacuous sampler conditioning.** The carrier's assumes never mention a sampler draw, `g` or `d`.
- **Each mutant fails for the intended reason.**
  - Every mutant run must be `Falsified`.
  - The named assertion is checked from the backend playback (`named == [violated]`, exactly one).
  - The decoded graph's native `D`/`G` must be the required mismatch.
  - Each probe is a separate run with one cover. `Verified` there means the cover was satisfied:
    `classify.rs:279` grants `Verified` only when all covers are satisfied.
  - The healthy oracle is `Verified`, so the oracle does not reject every sampler.
- **The seam does not diverge from the real renderer.** It calls `lower_graph` then `render_graph`,
  the same pair `negotiate.rs:1214`/`:469` use in production. It only overwrites `maximum` and
  `edge.upper`. `a_bound_mutant_changes_only_...` confirms that the identity differs only there and
  in the symbols and options derived from the digest. `#[cfg(test)] pub(crate)` in the production
  file is acceptable, because `render_graph`/`lower_graph` are `pub(super)` and there is precedent
  (`kani_graph_private`).
- **Dormant zeroing is sound for these samplers.** Every draw range starts at 0, and dormant
  slots are guarded by `object_count <= row || degree <= column`.

The findings are:

- the macro-defined Kani controls are invisible to the trace scanner;
- the carrier box constrains active values, not only padding, with no evidence check;
- `observe` ignores unrecognized statements;
- a test name that overclaims;
- sampled rather than exhaustive padding evidence.

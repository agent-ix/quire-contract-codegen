## Finding details

### FND-001

At the new test, the input is `Vec<CheckedSemanticNodeV2>` built by a local helper, collected into `Graph`, and passed to `FunctionSourceIndex::new`. The public generator could stop using that index in `item_disposition` while this test remains green. The ticket calls for actual-admission K/R request families and one build per retained batch. Extend a reader-admitted function package fixture to make K items and R functions, meter visits through `generate_exact_function_oracles`, and record all nine cells after the #513 rebase.

### FND-002

The existing TC-031 suite covers individual output and refusal properties, but this PR adds no comparison of complete public outputs captured before the indexing change and after it for the same admitted request family. The ticket specifically asks for dispositions, occurrences, bytes, refusals and consumed work, plus a refused sibling and multiple authorities. Record and compare those outputs in a focused fixture or a measured before/after report before claiming the IR-988 function slice satisfies acceptance check 3.

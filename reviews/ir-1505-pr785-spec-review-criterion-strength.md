## Verdict

CHANGES REQUIRED. Jev (typesafe.ai System One) is not installed here, so this analysis was done by hand. Can fail as written: the Invocation-instead-of-Current mutant fails step 39's form check, and QSL also refuses it as WrongObservation. The always-bind-0 mutant fails step 40's balance = -1 case, since 0 >= 0 holds. Swapping the strengthened mutant's package for the unmutated one fails step 40's first assertion. Weak: the satisfying-playback expectation is misstated, the unmutated control passes on any error, the by-position mutant has no distinguishing fixture, and one control names no CG mutation site.

Fix: name both mutation sites and the assertion each fails. | spec/replay/matrix/TC-035-counterexample-envelope-intake.md:361-365 |

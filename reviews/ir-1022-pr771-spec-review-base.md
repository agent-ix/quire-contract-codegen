## Summary

Ticket: IR-1022 (design decision D1 on IR-1436). Spec-only PR #771 (head 36dc18d1, one commit on origin/main 67739cf5) specifying the two-phase Kani run: a proof phase under a proof option vector with no concrete playback, then, only after a failed non-unwinding check, a witness phase under the witness vector. Edits FR-015 (Outputs, AC-9, AC-41, AC-119), FR-017 (Description, Inputs, Behavior, AC-5, AC-21, AC-60, new AC-63), FR-028 (Behavior, AC-23), FR-029 (witness-disagreed row), FR-032 (replay input), TC-025, TC-027, TC-039 and tests.md. Reviewed against CG origin/main 67739cf5 src/kani/abi.rs:108-134 (adapter_options), src/kani/generate/spec.rs:1286-1311 (HarnessSpec::new_constrained), src/kani/identity.rs:393/624/810 (has_valid_provenance), src/kani/run/harness.rs:91-99, src/kani/run/execute.rs:400-440/834-890, src/kani/classify.rs:26-53/166-260, src/kani/output/report.rs:231-240/624-637, src/kani/output/playback.rs, src/kani/run/scalar.rs:347-373, src/kani/terminal.rs; Contract IR 43ef764 src/kani/outcome.rs (KaniOutcomeKind); quire-exact origin/main TC-931 Status and Linear IR-844 (19,671,392,256 B traced 40 GiB probe vs 8,183,332,864 B healthy sliced); quire matrix on the PR head.

## Verdict

CHANGES REQUIRED. Verified against CG origin/main 67739cf5 src/kani/abi.rs:108-134 (adapter_options), src/kani/generate/spec.rs:1286-1311 (HarnessSpec::new_constrained), src/kani/identity.rs:393/624/810 (has_valid_provenance), src/kani/run/harness.rs:91-99, src/kani/run/execute.rs:400-440/834-890, src/kani/classify.rs:26-53/166-260, src/kani/output/report.rs:231-240/624-637, src/kani/output/playback.rs, src/kani/run/scalar.rs:347-373, src/kani/terminal.rs; Contract IR 43ef764 src/kani/outcome.rs (KaniOutcomeKind); quire-exact origin/main TC-931 Status and Linear IR-844 (19,671,392,256 B traced 40 GiB probe vs 8,183,332,864 B healthy sliced); quire matrix on the PR head. The decision is carried faithfully where it is stated: the proof vector drops both concrete-playback options, and the witness vector inserts -Z concrete-playback before --harness and appends --concrete-playback print, which matches adapter_options byte for byte. The witness launches only after a failed non-unwinding check. Falsified needs the same class and location plus a printed playback. Disagreement gives WitnessDisagreed, a witness resource stop is Inconclusive with ceilings unchanged, and a failing batch member is relaunched alone or with equal-vector peers. The code can tell an unwinding failure from any other: report checks carry class `unwind` (KaniCheckClass::Unwind, failed_unwinding / failed_property). Batch grouping still works for the witness vector, because without_selection removes only --harness X --exact, so -Z concrete-playback survives as a shared option. FR-032's replay input (the witness-phase playback) and FR-017-AC-58/60 (playback is not a proof verdict and leaves the sealed identity unchanged) are consistent. FR-029 Failed for witness_disagreed matches its siblings: NoVerdict, MissingCoverSummary and FailedWithoutCounterexample/properties_failed all map to Failed as tool faults, and only resource stops map to Incomplete. The PR introduces no hashes, digests or pins. Defects: the PR keeps rewritten criteria marked as covered, misdescribes today's seal check, leaves the batch playback rules in single-phase form, does not resolve the mixed unwinding/assertion report, and does not bind the playback to the matching check.
